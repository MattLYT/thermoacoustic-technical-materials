## Supplemental Experimental Procedures

## Details of Experiment Configuration

The experiment setup of the present system is illustrated in Figure S1, and the main geometric dimensions are listed in Table S1 in detail. The diameter of the engine is smaller than that of cooler for the better energy-flow field synergy and reducing loss. The HHX and CHX are the plate-fin type, whereas the AHXs of engine and cooler are the shell-tube type to realize better heat transfer between the working gas and cooling water. In particular, the AHX of cooler employs a double-pipe configuration, in which a large tube (3.2 mm in diameter) and four small tubes (1 mm in diameter) are welded together. Accordingly, the heat transfer area is enlarged by several times to enhance heat transfer. The geometric parameters are optimized by the numerical method which will be described subsequently.

In the experiment, there are five parameters involved for measurements: the operating frequency, mean pressure, oscillating pressure, temperature, and power. The temperature contains heating, ambient and cooling temperatures, which are measured by installing thermocouples into the HHX (K-type), cooling water pipe (T-type) and CHX (T-type), respectively. The power is given by electricity for heating: after reaching equilibrium, for the HHX, the heating power given is measured the electric power; regarding the CHX, according to the energy-conservation law, the cooling power is equal to the imposed heating power, i.e., the given electric power. ## Post Processing of Data

The COP is obtained by the ratio of cooing power and heating power, as follows

$$
\mathrm { C O P } = { \frac { \dot { Q } _ { c } } { \dot { Q } _ { h } } }\tag{S1}
$$

In this study, both of $\dot { Q } _ { c }$ and ${ \dot { Q } } _ { h }$ are tested by direct electric heating, thus they can be directly measured by the electric power meter. The heating power ${ \dot { Q } } _ { h }$ represents the thermal energy absorbed by the HHX, in which the heat leak of insulation materials is not considered. This is more reasonable to understand the intrinsic performance of the proposed system, because the heat leak of insulation materials can be changeable depending on the materials used for insultation (i.e., it could reach a low value near zero with the improvement of insulation materials). The heat leak $\dot { Q } _ { l e a k , m }$ of insulation materials can be estimated by

$$
\dot { Q } _ { l e a k , m } = \dot { Q } _ { l e a k , t o t a l } - \dot { Q } _ { l o s s , i n }\tag{S2}
$$

where $\dot { Q } _ { l e a k , t o t a l }$ and $\dot { Q } _ { l o s s , i n }$ denote the total heat leak and intrinsic internal heat loss. The total heat leak is obtained by the experiment: At the static situation (i.e., the system does not operate thus without oscillation), when the system reaches thermal equilibrium at the given heating temperature, the total heat leak is equal to the heat added (i.e., the heating power displayed), thus can be measured by the electric power meter.

For engine, the intrinsic internal heat loss mainly occurs in REG and TBT<sub>1</sub>, because they are the only two components with enormous axial temperature gradient in engine. Our tests indicate that the natural heat convection in the REG (due to the top-placed hot end and the bottom-placed cold end) has negligible impact in the intrinsic heat loss of the system at the non-oscillating condition, thus is not considered in this study. Therefore, in the REG, the intrinsic internal heat loss contains three parts of heat conduction: the heat conduction of solid wall, mesh screen, and working gas. According to Fourier’s law, it can be expressed by

$$
\left. \dot { Q } _ { l o s s , i n } \right| _ { R E G } = [ k _ { s w } A _ { s w } \frac { d T } { d x } + \beta k _ { m s } A _ { m s } \frac { d T } { d x } + k _ { g } A _ { g } \frac { d T } { d x } ] \bigg | _ { R E G }\tag{S3}
$$

where k and A represent the thermal conduction coefficient and area, respectively; the subscript sw, ms and g denote the solid wall, mesh screen and gas, respectively; $\beta$ is the heat conductivity degradation factor, which is reasonably to be set to 0.1 for the stainless

steel mesh screen<sup>1</sup>. There is no mesh screen in the $\mathrm { T B T _ { 1 } ; }$ therefore, the intrinsic internal heat loss in $\mathrm { T B T _ { 1 } }$ can be given as

$$
\left. \dot { Q } _ { l o s s , i n } \right. _ { T B T _ { 1 } } = \left[ k _ { s w } A _ { s w } \frac { d T } { d x } + k _ { g } A _ { g } \frac { d T } { d x } \right] \Bigr \vert _ { T B T _ { 1 } }\tag{S4}
$$

Hence, the intrinsic internal heat loss can be calculated by

$$
\dot { Q } _ { l o s s , i n } = \dot { Q } _ { l o s s , i n } \big | _ { R E G } + \dot { Q } _ { l o s s , i n } \big | _ { T B T _ { 1 } }\tag{S5}
$$

The obtained $\dot { Q } _ { l e a k , t o t a l }$ and $\dot { Q } _ { l e a k , m }$ are given in Figure S3.

After obtaining the heat leak of insulation materials by combining Equations (S2- S5), the heating power absorbed by the HHX can be estimated by

$$
\dot { Q } _ { h } = \dot { Q } _ { h , t o t a l } - \dot { Q } _ { l e a k , m }\tag{S6}
$$

where $\dot { Q } _ { h , t o t a l }$ is the heating power measured by the electric power meter.

The cooling power $\dot { Q } _ { c }$ is directly measured by the electric power meter. The energy balance of the solid in CHX indicates that the cooling power (which cools the solid) is equal to the given electric power (which heats the solid) when the solid temperature reaches a stable value. The real cooling power could be even larger due to the heat leakage of the insulation material wrapped around the CHX, which is not considered with the given small temperature span $( T _ { 0 } - T _ { c } = 2 8 \mathrm { K } )$ for conservative estimates. Accordingly, the COP can be calculated using Equation (1). Subsequently, the relative Carnot efficiency $\eta _ { C }$ can be obtained by

$$
\eta _ { C } = \frac { \mathrm { C O P } } { \mathrm { C O P } _ { C } } = \mathrm { C O P } \frac { \displaystyle \frac { T _ { 0 } } { T _ { c } } - 1 } { 1 - \displaystyle \frac { T _ { 0 } } { T _ { h } } }\tag{S7}
$$

## Error Analysis of Measurement

The measurement uncertainty of operating frequency and electric power (which estimates the heating and cooling power) can be directly obtained by the uncertainty of the corresponding measurement sensor displayed in Table S2.

For COP, it is the ratio of cooling power $\dot { Q } _ { c }$ and heating power ${ \dot { Q } } _ { h }$ . Due to $\dot { Q } _ { c }$ and ${ \dot { Q } } _ { h }$ are independent and random, the uncertainty of COP can be estimated $\mathsf { b y } ^ { 2 }$

$$
\frac { \delta \mathrm { C O P } } { \mathrm { C O P } } = \sqrt { ( \frac { \delta \dot { Q } _ { c } } { \dot { Q } _ { c } } ) ^ { 2 } + ( \frac { \delta \dot { Q } _ { h } } { \dot { Q } _ { h } } ) ^ { 2 } }\tag{S8}
$$

## Simulation Method

This study employs the SAGE program<sup>3</sup> to conduct the numerical investigation (shown in Figure 1C), as well as the design and optimization of the present experimental setup (listed in Table S1). SAGE is widely used for the simulation and design of thermoacoustic systems<sup>4-6</sup>. The optimization is to achieve a highest COP. The simulation model employs three equations of fluid mechanics, i.e., the continuity, momentum, and energy equations, which are outlined below<sup>7</sup>

$$
\frac { \partial \rho A _ { f } } { \partial t } + \frac { \partial \rho u A _ { f } } { \partial x } = 0\tag{S9}
$$

$$
\frac { \partial \rho u A _ { f } } { \partial t } + \frac { \partial \rho u ^ { 2 } A _ { f } } { \partial x } + \frac { \partial p } { \partial x } A _ { f } - F A _ { f } = 0\tag{S10}
$$

$$
\frac { \partial \rho e A _ { f } } { \partial t } + p \frac { \partial A _ { f } } { \partial t } + \frac { \partial } { \partial x } ( \rho u e A _ { f } + u p A _ { f } + \dot { q } ) - \dot { Q } _ { c v } = 0\tag{S11}
$$

where $\rho ,$ u and $e$ denote the density, velocity, and internal energy per unit mass of the gas, respectively; F denotes the viscous terms in the Stokes stress tensor and $A _ { f }$ denotes the flow area of the channel; $p , \dot { q }$ and $\dot { Q } _ { c v }$ are the oscillating pressure, axial heat flow and heat flow per unit length due to the convective heat transfer, respectively; t denotes time and x denotes axial dimension. The terms $F ,$ q and $\dot { Q } _ { c v }$ are given as follows

$$
F = - ( f _ { D } / d _ { h } + K _ { l o s } / l ) \rho u | u | / 2\tag{S12}
$$

$$
q = - N _ { k } k A _ { f } { \frac { \partial T } { \partial x } }\tag{S13}
$$

$$
\dot { Q } _ { c v } = N u ( k / d _ { h } ) S _ { x } ( T _ { s } - T )\tag{S14}
$$

where $f _ { D } , d _ { h }$ and $K _ { l o s }$ denote the Darcy friction factor, hydraulic diameter and total local loss coefficient, respectively; $N _ { k }$ is the ratio of the effective gas conductivity to the molecular conductivity; Nu, k, S<sub>x</sub> and $T _ { s ^ { - } } T$ are the Nusselt number, gas thermal conductivity, wetted perimeter and temperature difference between the solid and gas. $f _ { D } ,$ Nu and $N _ { k }$ are empirically calculated in Sage software, shown in Table S3.

The water in the liquid resonator is considered as incompressible liquid, thus can be simulated using the Reciprocator module in Sage due to the incompressible liquid approximation. The equivalent stiffness coefficient K and damping coefficient $R _ { m }$ for the liquid can be calculated using the following equations<sup>8</sup>:

$$
K = \frac { { { \rho } _ { l i q } } g \pi { { D } _ { l i q } } ^ { 2 } } { 2 }\tag{S15}
$$

$$
R _ { m } = \pi ^ { 1 . 5 } D _ { l i q } l _ { l i q } \sqrt { \rho _ { l i q } \mu _ { l i q } f } + 0 . 8 4 \pi ^ { 2 } \rho _ { l i q } f X _ { l i q } ( D _ { l i q } / 2 ) ^ { 2 } E\tag{S16}
$$

where the subscript liq denotes the water; $g , D , l \mu$ denote the gravitational acceleration, diameter, length and dynamic viscosity, respectively; X is the displacement amplitude and E is a coefficient estimating the total minor loss.

The total energy flow $\dot { H } _ { 2 }$ can be expressed in frequency domain based on the classical thermoacoustic theory<sup>9</sup>, and the heat exchange $\dot { Q }$ of the heat exchangers (AHX, HHX, and CHX) can be calculated by the difference in $\dot { H } _ { 2 }$ between the outlet and inlet. The expressions are as follows

$$
\dot { H } _ { 2 } = \frac { 1 } { 2 } p _ { 1 } \widetilde { U } _ { 1 } \left[ 1 - \frac { \left( f _ { \kappa } - \widetilde { f } _ { \nu } \right) } { ( 1 - \widetilde { f } _ { \nu } ) ( 1 + P r ) } \right] + \frac { \rho _ { m } c _ { p } | U _ { 1 } | ^ { 2 } } { 2 A _ { f } \omega ( 1 - P r ) ^ { 2 } | 1 - f _ { \nu } | ^ { 2 } } \mathrm { I m } [ f _ { \kappa } - f _ { \kappa } ] ,
$$

$$
+ \widetilde { f } _ { \nu } P r \} \frac { d T _ { m } } { d x } - ( A _ { g } k _ { g } + k _ { s w } A _ { s w } + \beta k _ { m s } A _ { m s } \frac { d T } { d x } ) \frac { d T _ { m } } { d x }\tag{S17}
$$

$$
\dot { Q } = \dot { H } _ { 2 , o u t } - \dot { H } _ { 2 , i n }\tag{S18}
$$

where the subscripts in and out denote the inlet and outlet of the heat exchanger, respectively; $\omega$ denote the angular frequency; $f _ { \kappa }$ and $f _ { \nu }$ are the spatially averaged viscous and thermal functions reflecting the flow and heat transfer, respectively, determined by the geometric structure of the flow channel and the property of the working gas. For the plate-fin heat exchanger (i.e., HHX and CHX), the expressions are as follows:

$$
f _ { \nu , \kappa } = \frac { \operatorname { t a n h } \left[ ( 1 + i ) y _ { 0 } / \delta _ { \nu , \kappa } \right] } { ( 1 + i ) y _ { 0 } / \delta _ { \nu , \kappa } }\tag{S19}
$$

where $y _ { 0 }$ is half of the fin spacing, $\delta _ { \nu }$ and $\delta _ { \kappa }$ are the viscous and thermal penetration depths of the gas, respectively. While for the shell-tube heat exchanger (i.e., AHX), the corresponding expressions are:

$$
f _ { \nu , \kappa } = \frac { 2 J _ { 1 } [ ( i - 1 ) r / \delta _ { \nu , \kappa } ] } { J _ { 0 } [ ( i - 1 ) r / \delta _ { \nu , \kappa } ] ( i - 1 ) r / \delta _ { \nu , \kappa } }\tag{S20}
$$

where $J _ { 0 }$ and $J _ { 1 }$ are the zero-order and first-order Bessel functions, respectively, r is the radius of the heat-exchange tube. The $\delta _ { \nu }$ and $\delta _ { \kappa }$ are expressed as follows

$$
\delta _ { \nu } = \sqrt { 2 \nu / \omega }\tag{S21}
$$

$$
\delta _ { \kappa } = \sqrt { 2 \kappa / \omega }\tag{S22}
$$

where � and � are the kinematic viscosity and thermal diffusivity of the gas, respectively.

The expressions of $\dot { r } _ { v }$ and $r _ { k }$ (the viscous and thermal resistance per unit length, respectively), are given by

$$
r _ { v } = \frac { \omega \rho _ { m } } { A _ { f } } \frac { \mathrm { I m } [ - f _ { \nu } ] } { | 1 - f _ { \nu } | ^ { 2 } }\tag{S23}
$$

$$
{ \frac { 1 } { r _ { \kappa } } } = { \frac { \gamma - 1 } { \gamma } } { \frac { \omega A _ { f } } { p _ { m } } } { \mathrm { I m } } [ - f _ { \kappa } ]\tag{S24}
$$
