# 热声技术资料库

本库保存热声及相邻回热式热机的原始资料与阅读版。实体目录先按资料性质、再按主要研究对象归档；装置功能、驱动链、工程型式和证据状态通过元数据分别检索。

- [[资料主题.base|资料主题]]：按资料类别、输入与功能、工程型式和证据状态浏览；
- [[专业名词与分类规则|专业名词与分类规则]]：目录收录边界、三级装置字段和理化所优先用语；
- [[文献整理入口|文献整理入口]]：原文、阅读版、图片和同源副本的追溯方法；
- [23_科研竞争图谱来源分类补录](索引/23_科研竞争图谱_来源分类补录.csv)：按本库资料类别登记该目录中的原始来源，并标出同源副本；
- [[资料库审计.base|资料库审计]]：资料库报告和审计入口。

## 实体目录

| 一级 | 二级 |
|---|---|
| 论文与研究报告 | 原理与综述；热声发动机与发电；制冷机与热泵；关键部件与测量；系统集成与联供 |
| 专利 | 整机与流程；部件与控制 |
| 机构与产品资料 | 科研项目与示范；产品规格与厂商资料 |
| 交流与原始素材 | 访谈与纪要；截图与音视频 |

每份资料在二级目录下有一个独立资料包：`source/` 保存原始文件，唯一文件名的 Markdown 是阅读入口，`images/` 保存其引用的派生图片。只有来源或只有阅读版的条目如实保留，不强制补造另一半。跨类别信息用元数据表示；同一原文的副本以 `same_source_as` 关联，统计时按唯一来源计数。

## 证据规则

- 同一层比较：`COP_ac` 只和 `COP_ac` 比，`COP_unit` 只和 `COP_unit` 比，客户 ROI 还要看 `COP_sys`；
- `P_e,total` 至少说明驱动器、功放、泵、风扇、控制、气体处理和热端散热是否计入；
- 模型、相对 Carnot、厂商规格、项目目标和宣传材料不自动等于整机实测；
- 历史输入保存在 `source/` 仍保持原有来源角色，不得据此升级为技术 A 级证据；
- 访谈、会议和口述价格必须标注交流对象、日期、记录方式与核验状态；合同、报价、项目现状和人员经历在取得原件或当事人确认前保持 `oral-unverified`；
- 场景有痛点不等于电驱声制冷已经胜出，必须有同边界性能、成本、可靠性或可用率数据。
